# 照片水印工具 GUI 版 v1.0

一个简单易用的照片水印添加工具，支持批量处理和实时预览。

## 功能特点

### 核心功能
- ✅ **多格式支持**：支持 JPEG、PNG、BMP、TIFF、WebP 等主流图片格式
- ✅ **自动读取EXIF**：自动读取照片拍摄日期作为水印文本
- ✅ **实时预览**：所见即所得的实时预览功能
- ✅ **批量处理**：一次性处理多张照片
- ✅ **模板系统**：保存和重用常用水印设置

### 水印设置
- 📝 **文本设置**：自定义水印文本内容
- 🎨 **颜色选择**：支持自定义水印颜色
- 📏 **字体大小**：10-100 像素可调
- 💧 **透明度控制**：10%-100% 透明度调节
- 📍 **九宫格定位**：快速选择9个预设位置
- 📐 **边距调整**：0-100 像素边距设置

### 高级功能
- 🔄 **旋转角度**：支持 -180° 到 180° 任意角度旋转
- 🌑 **阴影效果**：增强水印在复杂背景下的可读性
- ✏️ **描边效果**：为水印添加描边增强视觉效果

## 使用说明

### 快速开始

1. **启动应用**
   ```bash
   python app.py
   ```
   或双击运行打包后的 `.exe` 文件

2. **导入图片**
   - 点击"导入图片"按钮选择单个或多个图片文件
   - 点击"导入文件夹"按钮选择包含图片的文件夹
   - 快捷键：`Ctrl+O` (图片) / `Ctrl+Shift+O` (文件夹)

3. **设置水印**
   - 在左侧设置面板调整水印参数
   - 选择预设模板或自定义设置
   - 实时在右侧预览区查看效果

4. **导出图片**
   - **单张导出**：点击"应用到当前"保存当前图片
   - **批量导出**：点击"批量导出"处理所有图片
   - 快捷键：`Ctrl+S` (批量导出)

### 模板管理

#### 保存模板
1. 调整好水印设置
2. 菜单栏选择 `模板` → `保存当前设置为模板`
3. 输入模板名称并保存

#### 使用模板
- 在设置面板顶部的下拉菜单中选择已保存的模板
- 模板会自动应用所有设置

#### 导入/导出模板
- `模板` → `导出模板`：将当前模板保存为 `.json` 文件
- `模板` → `导入模板`：从 `.json` 文件加载模板

## 设置说明

### 基本设置

- **水印文本**：显示在图片上的文字内容
  - 支持占位符：`YYYY`(年)、`MM`(月)、`DD`(日)
  - 留空则自动使用EXIF日期

- **字体大小**：控制水印文字的大小（10-100像素）

- **颜色**：点击颜色按钮选择水印颜色

- **透明度**：调整水印的不透明度（10%-100%）

- **位置**：九宫格快速定位
  - 左上、正上、右上
  - 左中、居中、右中
  - 左下、正下、右下

- **边距**：水印距离边缘的距离（0-100像素）

### 高级设置

- **旋转**：旋转水印角度（-180° 到 180°）
- **启用阴影**：为水印添加阴影效果，提高可读性
- **启用描边**：为水印文字添加描边效果

## 文件格式

### 支持的输入格式
- JPEG / JPG

## 常见问题

### Q: 水印显示不清晰？
A: 尝试以下方法：
- 增大字体大小
- 启用阴影或描边效果
- 调整水印颜色与背景形成对比
- 调整透明度

### Q: 批量处理失败？
A: 检查：
- 输出目录是否有写入权限
- 磁盘空间是否充足
- 图片文件是否损坏

### Q: 无法读取EXIF日期？
A: 部分图片可能没有EXIF信息，此时：
- 手动输入水印文本
- 程序会尝试使用文件创建时间

### Q: 如何调整输出图片质量？
A: 当前版本默认质量为90，如需调整：
- 修改 `core/watermark_engine.py` 中的 `quality` 参数
- 或在批量导出时指定质量参数
